# Чек-лист перед публичным запуском

Пункты со снятой галочкой закрыты кодом. Остальное — ручные действия
при развёртывании.

## Критично — без этого запускаться нельзя

- [x] **Секретный ключ.** При `DJANGO_DEBUG=0` сайт не стартует со
  значением по умолчанию: ключ подписывает сессии, и со стандартным
  значением сессию модератора можно подделать. Сгенерировать:
  `python -c "import secrets; print(secrets.token_urlsafe(64))"`
- [x] **DEBUG=False.** При включённом DEBUG страница ошибки показывает
  фрагменты кода, настройки и содержимое переменных окружения.
- [x] **ALLOWED_HOSTS.** Значение `*` в боевом режиме запрещено явной
  проверкой.
- [x] **HTTPS.** Редирект, secure-куки, HSTS на год, `X-Frame-Options: DENY`
  включаются автоматически при `DEBUG=False`. TLS-сертификат ставится
  на сервере — Let's Encrypt через Caddy или certbot.
- [ ] **PostgreSQL вместо SQLite.** SQLite блокирует базу при записи;
  бот и сайт пишут одновременно, под нагрузкой это даст ошибки. Убрать
  `USE_SQLITE=1`, заполнить `DB_*` в `.env`.
- [ ] **Файл `.env` не в репозитории.** Проверить: `git ls-files | grep .env`
  должен показать только `.env.example`.
- [ ] **Пароль модератора.** Не короче 12 символов, не переиспользованный.
- [ ] **Токен бота не публиковался** — ни в чатах, ни в коммитах. Если
  засветился, отозвать: `/revoke` у @BotFather.

## Защита от злоупотреблений

- [x] **Лимит заявок.** 5 в час и 20 в сутки с одного аккаунта,
  настраивается через `REPORTS_PER_HOUR` / `REPORTS_PER_DAY`.
- [x] **Блокировка пользователя.** Отметка «Заблокирован» в разделе
  «Авторы заявок» — бот перестаёт принимать заявки.
- [x] **Премодерация.** Ничто не попадает на карту без одобрения:
  новые заявки в статусе «На модерации» невидимы публично.
- [x] **Ограничение размера файла** — 12 МБ, больше бот не принимает.
- [x] **Только изображения.** Файлы и документы отклоняются, битые
  картинки отсекаются при обработке.
- [ ] **Fail2ban или лимит запросов на nginx** для страницы `/admin/` —
  защита от перебора пароля.
- [ ] **Резервное копирование.** База и папка с фотографиями, ежедневно,
  с хранением копий вне сервера. Восстановление проверить один раз
  вручную — непроверенный бэкап не считается бэкапом.

## Приватность

- [x] **EXIF удаляется.** Вместе с метаданными вырезаются GPS-координаты
  съёмки — глазами при модерации их не увидеть.
- [x] **Фото на модерации недоступны публично.** Снимок неопубликованной
  заявки отдаётся только сотруднику.
- [x] **API не отдаёт лишнего.** Ни автора заявки, ни модератора, ни
  служебных заметок — состав полей задан явно.
- [x] **Согласие на публикацию.** Бот прямо предупреждает, что фото
  станет открытым, и напоминает не снимать лица и номера машин.
- [x] **Обход каталога заблокирован** в файловом хранилище.
- [ ] **Проверка кадра при модерации.** Лица, номера автомобилей,
  таблички с номерами квартир — основание отклонить заявку.
- [ ] **Порядок удаления по запросу.** Бот принимает обращения командой
  `/delete`; решить, кто и в какой срок их обрабатывает.
- [ ] **Юридическая проверка.** Публикация фотографий городской среды,
  собранных от жителей, регулируется местным законодательством о
  персональных данных. Сверьтесь с юристом в Узбекистане — здесь
  универсального ответа нет.

## После запуска

- [ ] `python manage.py check --deploy` — должно быть чисто
- [ ] Проверить, что `http://` редиректит на `https://`
- [ ] Открыть `/admin/` в анонимном окне — должна быть форма входа
- [ ] Открыть `/media/<id>/` неопубликованной заявки анонимно — 404
- [ ] Обновление зависимостей раз в квартал: `pip list --outdated`
